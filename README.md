# Pomo - Premium Pomodoro Timer

Pomo is a premium, dark-mode web application designed to help anyone lock into deep study or work sessions without any distractions.

## Description

This project is a clean, no-nonsense Pomodoro timer built completely from scratch using raw HTML, CSS, and vanilla JavaScript. It features an premium interface, smooth hover animations. I built this 100% manually without using any AI code generators to completely master frontend fundamentals, DOM manipulation, and CSS keyframe animations by hand.

## Executing program

* Open your local pomo folder.
* Double-click the index.html file to instantly launch the timer in your default browser.
* Alternatively, visit the live production link hosted on [Vercel](https://pomo-beige.vercel.app/).
